# 商品功效证据与体验声明核验

把广告功效声明与批准文件、研究资料和真实体验证据绑定。

## 参与方与事实

主要参与方包括品牌合规人员、医学审查人员、产品负责人、广告制作人员。领域资料记录以下事实：

- 数字人会以第一人称声称亲自使用并有效
- 没有感知能力的角色不能产生真实体验
- 食品、药品和医疗器械的宣传事实需要可核对来源

## 业务边界

- 证据来源
- 适用人群
- 体验主体
- 有效期限
- 撤回影响

当前资料按以下边界组织：

- 产品主张
- 证据包
- 体验声明
- 地域版本
- 过期撤回

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/evidence_context.py` 负责读取和校验资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

命令只读取仓库内文件，不需要连接外部业务系统。
